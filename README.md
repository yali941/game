# 一局 · 好友棋室

极简中文棋类小游戏合集：五子棋、2～4 人飞行棋、双人斗兽棋。支持电脑和手机、好友联机、房间邀请、断线重连、同屏对弈及各游戏独立胜场榜。所有游戏行棋不限时。

## 桌游交互更新

- 飞机图案沿实际移动方向转向，停下后朝向下一格；包括转弯、终点跑道、反弹、飞跃和回仓。

- 聊天气泡按发言阵营配色，昵称使用同一身份，公开 ID 保留在提示中。
- 聊天、胜场榜和骰子旁行动提示使用同一玩家昵称。修改昵称后，同步到已加入的房间和历史聊天消息。
- 飞行棋允许掷出 2、4、6 点出仓；只有 6 点可续掷，连续第三个 6 将本回合前两次动过的飞机送回机库并结束回合。

- 三个游戏均支持棋室聊天，显示昵称和公开玩家 ID，刷新恢复房间内最近 100 条消息；消息以纯文本展示，限制 200 字和每秒一条。
- 增加哭哭脸互动，以及可随时取消的托管。联机托管由服务器负责，同屏可以分别开启双方或多方托管。五子棋优先成五/防守，斗兽棋考虑合法吃子与风险，飞行棋自动掷骰和选机；托管不会给普通回合添加时间限制。
- 托管玩家断线时可继续行棋；未托管玩家离线或等待五子棋协商时暂停。新联机对局默认关闭托管。
- 飞行棋按归航顺序记录名次，直到只剩最后一名才结束；已完成玩家自动停止托管，断线不阻塞剩余玩家。覆盖 2/3/4 人完整对局、跳过已完成回合、断线续玩及胜场计分测试。
- 飞行棋行动方以阵营颜色显示在骰子旁边，棋子改为更纯的颜色、加厚侧面、白色轮廓和明显投影。
- `node --test` 共 33 项测试通过，包括新增聊天隔离、身份校验、历史恢复、哭哭脸、托管合法走法、取消和暂停的测试。

- 五子棋：木质棋盘与竹叶点缀。第一次点击交叉点预选，第二次点击同一位置确认落子；棋子下落停稳后播放连珠动效。
- 飞行棋：彩色正圆飞机筹码，移动时跳动和飞跃。左下方独立掷骰区展示翻滚、弹起和落稳，骰子停稳后只显示正面点数。
- 斗兽棋：木框草地棋盘与动物头像，红蓝双方棋子使用对应底色。走子有跳跃和落地回弹，狮虎跳河的弧线更高。
- 棋手状态和操作集中在棋盘区域，悔棋与求和请求在棋盘上弹出；联机双方同步播放动作，行棋仍然不限时。

## 启动

需要 Node.js 20 或更新版本，无需安装依赖。

```sh
node server.js
```

Windows 也可以双击 `启动游戏.cmd`。浏览器访问 `http://localhost:3000`。

没有云服务器时，可以用 GitHub + Render 部署。本目录已包含免费套餐的 `render.yaml`，具体见 [公网部署说明](./公网部署.md)。免费实例休眠或重启会丢失当前内存棋局，适合先试玩。

## 朋友怎么加入

1. **同一 Wi-Fi / 局域网**：两个人都打开启动窗口输出的局域网地址，例如 `http://192.168.1.10:3000`。一人点击「创建房间」，分享邀请链接或 6 位房间码；另一人加入。电脑上需要允许 Node.js 的本地网络访问，网络不能启用客户端隔离。
2. **不同网络 / 公网**：将整个目录部署到支持长期运行 Node.js 的服务器上，运行 `node server.js`，配置 HTTPS 和域名，双方打开相同域名。应用监听 `0.0.0.0`，端口使用环境变量 `PORT`（默认 3000）。仅把文件放到静态网站托管服务上不能实现联机。
3. **本机测试**：打开两个独立浏览器标签页，各自创建、加入同一房间。每个标签页独立保存棋手身份；直接复制已有棋局标签页可能复制身份，应从新的空白标签页输入地址。

邀请链接不会自动占座，点击房间码右侧箭头加入。`localhost` 仅指当前设备，分享给其他设备前请改用局域网地址或公网域名。

## 五子棋规则

- 15×15 棋盘，在交叉点落子，黑先白后，每次一枚，不可覆盖或移动棋子。
- 横、竖、两种斜向，连续五枚或更多同色棋子获胜。采用常见无禁手五子棋，非连珠竞赛禁手制。
- 双方均不限时，无超时判负。满盘无人获胜则和棋。
- 认输或主动离开，进行中的对局判对方获胜。单纯断网、刷新、关标签页不自动认输。
- 断线时暂停落子；恢复网络后自动重连，刷新原标签页会恢复身份和棋局。
- 结束后双方点击「再来一局」才清空棋盘，并交换黑白。
- 主动离开会关闭房间，不支持中途换人；新的一局可创建新房间。

## 保存与部署说明

棋局保存在服务端内存中，服务器重启会清空房间。双方离线满 24 小时的房间回收；这不会限制在线棋手的思考时间。身份凭证保存在当前标签页的 `sessionStorage`，关闭标签页后能否恢复取决于浏览器，建议在原标签页刷新重连。

前端和服务端同源，动作通过 HTTP POST 提交，状态通过 SSE 实时同步，由服务端校验身份、落点、轮次与胜负。使用单个 Node 进程，无需数据库和第三方运行时依赖。代理需支持 SSE，关闭 `/api/events` 的缓冲并保持长连接。服务器每 20 秒发送心跳。内存状态不适用于多副本负载均衡；如需多实例部署，应增加共享状态和消息服务。

Nginx 代理示例（放入已有 HTTPS server 配置）：

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header Connection "";
    proxy_buffering off;
    proxy_read_timeout 75s;
}
```

服务器限制最多 500 个同时保留的房间、每 IP 每分钟 180 次动作请求。公网部署时可在代理层增加访问与连接限制。

## 验证

```sh
node --test
```

包含四方向胜负、边界、长连、占位、轮次、满盘和棋，以及真实双客户端的创建、加入、身份校验、同步、断线恢复、再开交换执棋、认输与离开测试。

棋盘支持鼠标、触摸，也可 Tab 聚焦后用方向键选点、回车或空格落子。右上角可开启轻量落子音效。

## 悔棋、求和与互动

- 联机中点击「悔棋」或「求和」向对手申请，由对手同意或拒绝；申请者可以取消。等待回应时暂停落子，不设回应时限，刷新后请求仍保留。
- 悔棋退回到申请者最近一手之前；若对手已应手，一并撤回双方最近各一手，由申请者重下。棋局结束后不可悔棋。
- 求和获同意后，本局以和棋结束。双方可以确认再来一局。
- 可以给对手扔大便、送爱心或扔炸弹，双方同步看到动画。每位棋手每 2 秒可发送一次，仅限当前房间，不影响落子和胜负，重连不重播旧动画。
- 同屏模式的悔棋撤回最近一手，悔棋、和棋均通过双方共同确认的弹窗操作。
- 黑白棋子带柔和投影；互动动画支持系统的减少动态效果设置。

新增测试覆盖悔棋一手/两手、求和、同意/拒绝/取消、请求重连恢复、权限和过期请求校验、互动限频与房间隔离。

## 游戏大厅与联机胜场榜

首页为三款游戏的入口。五子棋位于 `/gomoku`，原有 `/?room=房间码` 邀请仍兼容；飞行棋与斗兽棋分别位于 `/play?game=flight` 和 `/play?game=jungle`。两款新增游戏均支持同屏、房间联机、断线暂停与重连、双方或全员确认再开、互动表情。

飞行棋支持 2～4 人，每方四架飞机。采用 2、4、6 点出仓、6 点连掷、连续第三个 6 将本回合动过的飞机送回机库并结束回合、同色跳四格、飞机标记格飞跃、撞机、终点反弹的规则。叠放飞机每次单独移动。每方四架全部抵达后记录名次并跳过回合，其余玩家继续；只剩最后一名时自动结束，完整显示所有名次。第一名计一场胜利。骰子由服务端以安全随机数生成，客户端不能指定点数；移动版本校验避免重复请求重复掷骰。创建房间时选定人数，人齐后房主开始。

斗兽棋采用 7×9 棋盘，红先蓝后；鼠猫狗狼豹虎狮象对应等级 1～8，鼠可吃象、象不可吃鼠，狮虎跳河、任意鼠挡跳、水陆不互吃、敌方陷阱降级、不可入己穴，入敌穴或令对手无合法走法即胜。细则在游戏内「玩法说明」可查。

每款游戏有独立的联机胜场榜，可设置昵称。匿名身份保存在当前浏览器的 localStorage；清除浏览器数据或更换设备会变成新的玩家。只统计不同身份、已经行棋的联机胜局，同屏、自我对弈、和棋和多人中途散局不计胜场。排名由服务端判定，每局只计一次。

战绩默认保存于 `data/rankings.json`；可用 `SCORE_FILE` 环境变量指定持久磁盘路径。代码包和镜像不包含本地玩家数据。Render Free 当前无持久磁盘，重新部署、平台替换或重启实例后战绩可能重置，界面已明确提示。要长期保留榜单，应将该路径放在持久卷，或改用托管数据库；当前版本未启用付费资源。

五子棋改为浅木色棋盘，棋子保留投影；获胜连线从最后一枚落子开始，依距离播放放大缩小动画。尊重系统减少动态效果设置。
