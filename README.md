# 一局 · 好友棋室

极简中文棋类小游戏合集：五子棋、19 路围棋、2～4 人飞行棋、双人斗兽棋，以及 2～8 人 UNO 派对、抽乌龟。支持电脑和手机、好友联机、房间邀请、断线重连、同屏对弈及各游戏独立胜场榜。所有游戏行棋不限时。

> 2026-09-24：新增 UNO 派对，无射箭牌；52 项规则与联机测试通过。新增玩法与本版细则见文末。

## 抽乌龟

- 大厅入口：`/play?game=oldmaid`，支持 2～8 人联机，抽牌不限时。
- 52 张标准扑克牌，加一张乌龟牌；发完牌自动消除同点数对子，不分花色。
- 顺时针从下一位仍有手牌的玩家处抽一张；空手玩家安全离场，其余继续，最后留下乌龟的人输。正常完局的其他玩家各记一胜，中途关闭房间不计分。
- 只发送玩家本人的手牌，对手只显示牌背与数量。手动调整牌序（点选后左右移动，电脑支持拖动）、洗乱手牌、随机托管、重连、再来一局、聊天、表情和独立胜场榜均可用。
- 木框绿毡圆桌，支持发牌、抽牌、消对动画，手机保留底部面板与悬浮聊天。
- `node --test`：65 项测试通过，涵盖 2～8 人牌量守恒、隐藏手牌、非法抽牌、重复请求、自动消对、托管和计分。

## 启动

需要 Node.js 20 或更新版本，无需安装依赖。

```sh
node server.js
```

Windows 也可以双击 `启动游戏.cmd`。浏览器访问 `http://localhost:3000`。

没有云服务器时，可以用 GitHub + Render 部署。本目录已包含免费套餐的 `render.yaml`，具体见 [公网部署说明](./公网部署.md)。免费实例休眠或重启会丢失当前内存棋局，适合先试玩。

## 朋友怎么加入

1. **同一 Wi-Fi / 局域网**：两个人都打开启动窗口输出的局域网地址，例如 `http://192.168.1.10:3000`。一人点击「创建房间」，分享邀请链接或 6 位房间码；另一人加入。电脑上需要允许 Node.js 的本地网络访问，网络不能启用客户端隔离。
2. **不同网络 / 公网**：将整个目录部署到支持长期运行 Node.js 的服务器上，运行 `node server.js`，配置 HTTPS 和域名，双方打开相同域名。应用监听 `0.0.0.0`，端口使用环境变量 `PORT`（默认 3000）。仅把文件放到静态网站托管服务上不能实现联机。
3. **本机测试**：打开两个独立浏览器标签页，各自创建、加入同一房间。每个标签页独立保存棋手身份；直接复制已有棋局标签页可能复制身份，应从新的空白标签页输入地址。

邀请链接不会自动占座，点击房间码右侧箭头加入。`localhost` 仅指当前设备，分享给其他设备前请改用局域网地址或公网域名。

## 五子棋规则

- 15×15 棋盘，在交叉点落子，黑先白后，每次一枚，不可覆盖或移动棋子。
- 横、竖、两种斜向，连续五枚或更多同色棋子获胜。采用常见无禁手五子棋，非连珠竞赛禁手制。
- 双方均不限时，无超时判负。满盘无人获胜则和棋。
- 认输或主动离开，进行中的对局判对方获胜。单纯断网、刷新、关标签页不自动认输。
- 断线时暂停落子；恢复网络后自动重连，刷新原标签页会恢复身份和棋局。
- 结束后双方点击「再来一局」才清空棋盘，并交换黑白。
- 选择「人机对弈」可与基础 AI 对局：玩家执黑先行，AI 执白应手；AI 会优先成五或拦截，不影响好友联机房间。
- 主动离开会关闭房间，不支持中途换人；新的一局可创建新房间。

## 保存与部署说明

棋局保存在服务端内存中，服务器重启会清空房间。双方离线满 24 小时的房间回收；这不会限制在线棋手的思考时间。身份凭证保存在当前标签页的 `sessionStorage`，关闭标签页后能否恢复取决于浏览器，建议在原标签页刷新重连。

前端和服务端同源，动作通过 HTTP POST 提交，状态通过 SSE 实时同步，由服务端校验身份、落点、轮次与胜负。使用单个 Node 进程，无需数据库和第三方运行时依赖。代理需支持 SSE，关闭 `/api/events` 的缓冲并保持长连接。服务器每 20 秒发送心跳。内存状态不适用于多副本负载均衡；如需多实例部署，应增加共享状态和消息服务。

Nginx 代理示例（放入已有 HTTPS server 配置）：

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header Connection "";
    proxy_buffering off;
    proxy_read_timeout 75s;
}
```

服务器限制最多 500 个同时保留的房间、每 IP 每分钟 180 次动作请求。公网部署时可在代理层增加访问与连接限制。

## 悔棋、求和与互动

- 联机中点击「悔棋」或「求和」向对手申请，由对手同意或拒绝；申请者可以取消。等待回应时暂停落子，不设回应时限，刷新后请求仍保留。
- 悔棋退回到申请者最近一手之前；若对手已应手，一并撤回双方最近各一手，由申请者重下。棋局结束后不可悔棋。
- 求和获同意后，本局以和棋结束。双方可以确认再来一局。
- 可以给对手扔大便、送爱心或扔炸弹，双方同步看到动画。每位棋手每 2 秒可发送一次，仅限当前房间，不影响落子和胜负，重连不重播旧动画。
- 同屏模式的悔棋撤回最近一手，悔棋、和棋均通过双方共同确认的弹窗操作。
- 黑白棋子带柔和投影；互动动画支持系统的减少动态效果设置。

新增测试覆盖悔棋一手/两手、求和、同意/拒绝/取消、请求重连恢复、权限和过期请求校验、互动限频与房间隔离。

## 游戏大厅与联机胜场榜

大厅现有六种玩法：五子棋、围棋、飞行棋、斗兽棋、UNO 和抽乌龟。

首页为六款游戏的入口。五子棋位于 `/gomoku`，原有 `/?room=房间码` 邀请仍兼容；围棋位于 `/go`，飞行棋与斗兽棋分别位于 `/play?game=flight` 和 `/play?game=jungle`，UNO 和抽乌龟见下文。均支持房间联机、断线暂停与重连、双方或全员确认再开、互动表情。

飞行棋支持 2～4 人，每方四架飞机。采用 2、4、6 点出仓、6 点连掷、连续第三个 6 将本回合动过的飞机送回机库并结束回合、同色跳四格、飞机标记格飞跃、撞机、终点反弹的规则。叠放飞机每次单独移动。每方四架全部抵达后记录名次并跳过回合，其余玩家继续；只剩最后一名时自动结束，完整显示所有名次。标准模式第一名计一场胜利，娱乐模式不计胜场。骰子由服务端以安全随机数生成，客户端不能指定点数；移动版本校验避免重复请求重复掷骰。创建房间时选定人数，人齐后房主开始。

斗兽棋采用 7×9 棋盘，红先蓝后；鼠猫狗狼豹虎狮象对应等级 1～8，鼠可吃象、象不可吃鼠，狮虎跳河、任意鼠挡跳、水陆不互吃、敌方陷阱降级、不可入己穴，入敌穴或令对手无合法走法即胜。细则在游戏内「玩法说明」可查。

每款游戏有独立的联机胜场榜，可设置昵称。匿名身份保存在当前浏览器的 localStorage；清除浏览器数据或更换设备会变成新的玩家。只统计不同身份、已经行棋的联机胜局，同屏、自我对弈、和棋和多人中途散局不计胜场。排名由服务端判定，每局只计一次。

战绩默认保存于 `data/rankings.json`；可用 `SCORE_FILE` 环境变量指定持久磁盘路径。代码包和镜像不包含本地玩家数据。Render Free 当前无持久磁盘，重新部署、平台替换或重启实例后战绩可能重置，界面已明确提示。要长期保留榜单，应将该路径放在持久卷，或改用托管数据库；当前版本未启用付费资源。

五子棋改为浅木色棋盘，棋子保留投影；获胜连线从最后一枚落子开始，依距离播放放大缩小动画。尊重系统减少动态效果设置。

## UNO 派对（2026-09-24）

入口 `/play?game=uno`，支持 2～8 人好友联机、独立胜场榜、托管和聊天室。暗青绿绒面牌桌；每位玩家始终位于自己的下方；视角只旋转位置，顺时针 / 逆时针顺序保持一致。可出的手牌上挑，万能牌在弹窗选色。手机复用聊天 / 房间 / 更多导航和半透明消息预览。

玩法参考《猛兽派对》爪爪牌，按要求排除射箭牌及箭牌。每人七张，同色 / 同数字 / 同图案接牌，先出完获胜。铲子跨色叠加 +2；冰冻枪跳过；回旋镖转向；电击摸到指定色或万能牌；隐身药水传递当前惩罚；炸弹引信到时罚四张；香蕉回到牌堆，抽中额外罚三张；惊喜蛋随机产生其他牌效果。没有经典 UNO +4、质疑和漏喊惩罚。

公开规则未提供完整牌堆配比、引信时长、惊喜蛋概率和全部边界处理，故不宣称逐项精确复刻。本版每副采用 120 张，2～4 人使用一副、5～8 人使用两副（每色 0 一张、1～9 与三种有色功能牌各两张，五种万能特殊牌各四张）；引信均匀随机 20～35 秒；蛋的 17 种非蛋、非射箭结果等概率；开局翻数字牌；最后一张出完立即获胜。普通回合不限时。断线且未托管时暂停对局和引信；爆炸不跳过被打断的回合，药水可传递爆炸后恢复原回合。

- 权威状态在服务端，牌堆和其他人的手牌不发送到客户端；HTTP 与 SSE 仅投影当前座位手牌。
- 洗牌、蛋和引信使用服务端 `node:crypto.randomInt`，客户端不能指定随机结果。
- 官方公开规则依据：[Party Animals Ver 1.5 历次公告](https://store.steampowered.com/news/posts/?enddate=1713594827&feed=steam_community_announcements)，其中 1.5.3.0 描述叠加铲子、电击、炸弹和香蕉；1.5.7.0 描述隐身药水。
- 新增 15 项测试：牌堆、手牌保密、视角顺序、非法操作、反转、叠罚、冰冻、电击、香蕉、摸牌、惊喜蛋、炸弹和药水中断恢复、结算、60 局完整模拟，以及真实四人 HTTP / SSE、聊天、托管、胜场和再开。
