# 一局 · 五子棋

极简纸感网页五子棋。中文界面，支持电脑和手机；真实双人联机、房间邀请、断线重连、双方同意再开一局，以及同屏对弈。双方落子不限时。

## 启动

需要 Node.js 20 或更新版本，无需安装依赖。

```sh
node server.js
```

Windows 也可以双击 `启动游戏.cmd`。浏览器访问 `http://localhost:3000`。

没有云服务器时，可以用 GitHub + Render 部署。本目录已包含免费套餐的 `render.yaml`，具体见 [公网部署说明](./公网部署.md)。免费实例休眠或重启会丢失当前内存棋局，适合先试玩。

## 朋友怎么加入

1. **同一 Wi-Fi / 局域网**：两个人都打开启动窗口输出的局域网地址，例如 `http://192.168.1.10:3000`。一人点击「创建房间」，分享邀请链接或 6 位房间码；另一人加入。电脑上需要允许 Node.js 的本地网络访问，网络不能启用客户端隔离。
2. **不同网络 / 公网**：将整个目录部署到支持长期运行 Node.js 的服务器上，运行 `node server.js`，配置 HTTPS 和域名，双方打开相同域名。应用监听 `0.0.0.0`，端口使用环境变量 `PORT`（默认 3000）。仅把文件放到静态网站托管服务上不能实现联机。
3. **本机测试**：打开两个独立浏览器标签页，各自创建、加入同一房间。每个标签页独立保存棋手身份；直接复制已有棋局标签页可能复制身份，应从新的空白标签页输入地址。

邀请链接不会自动占座，点击房间码右侧箭头加入。`localhost` 仅指当前设备，分享给其他设备前请改用局域网地址或公网域名。

## 规则

- 15×15 棋盘，在交叉点落子，黑先白后，每次一枚，不可覆盖或移动棋子。
- 横、竖、两种斜向，连续五枚或更多同色棋子获胜。采用常见无禁手五子棋，非连珠竞赛禁手制。
- 双方均不限时，无超时判负。满盘无人获胜则和棋。
- 认输或主动离开，进行中的对局判对方获胜。单纯断网、刷新、关标签页不自动认输。
- 断线时暂停落子；恢复网络后自动重连，刷新原标签页会恢复身份和棋局。
- 结束后双方点击「再来一局」才清空棋盘，并交换黑白。
- 主动离开会关闭房间，不支持中途换人；新的一局可创建新房间。

## 保存与部署说明

棋局保存在服务端内存中，服务器重启会清空房间。双方离线满 24 小时的房间回收；这不会限制在线棋手的思考时间。身份凭证保存在当前标签页的 `sessionStorage`，关闭标签页后能否恢复取决于浏览器，建议在原标签页刷新重连。

前端和服务端同源，动作通过 HTTP POST 提交，状态通过 SSE 实时同步，由服务端校验身份、落点、轮次与胜负。使用单个 Node 进程，无需数据库和第三方运行时依赖。代理需支持 SSE，关闭 `/api/events` 的缓冲并保持长连接。服务器每 20 秒发送心跳。内存状态不适用于多副本负载均衡；如需多实例部署，应增加共享状态和消息服务。

Nginx 代理示例（放入已有 HTTPS server 配置）：

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header Connection "";
    proxy_buffering off;
    proxy_read_timeout 75s;
}
```

服务器限制最多 500 个同时保留的房间、每 IP 每分钟 180 次动作请求。公网部署时可在代理层增加访问与连接限制。

## 验证

```sh
node --test
```

包含四方向胜负、边界、长连、占位、轮次、满盘和棋，以及真实双客户端的创建、加入、身份校验、同步、断线恢复、再开交换执棋、认输与离开测试。

棋盘支持鼠标、触摸，也可 Tab 聚焦后用方向键选点、回车或空格落子。右上角可开启轻量落子音效。
